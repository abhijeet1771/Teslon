## I3 — sound skips, framework knowledge as data (done)
Architecture: (1) facts per commit from TS checker + build-free Java resolver; unresolved → explicit Unknown(site, kind) fact. (2) Δ = fact diff (DiffBase style), cosmetic edits → empty Δ. (3) model packs: YAML rows (CodeQL MaD style) compiled to Datalog: entry(kind, matcher, area), channel(producer→consumer, key), summary (MapStruct), neutral; provenance manual/ai-verified + probe run. (4) core one Soufflé program: type-based dispatch over app classes + cheap points-to; library covered by Averroes separate-compilation assumption. (5) key string domain: constant | prefix | ⊤, resolved from application*.yml per profile; ⊤ matches all consumers. (6) Unknown → havoc: edges to every in-app method matching type/arity, else global ⊤ (Solar-like, pinned to a site, reported). (7) verdicts on G_base ∪ G_head: TEST = derivation path entry→Δ; SKIP = closed-set certificate; UNCLEAR = else, listing blocking Unknowns. (8) separate small checker (~300 lines, no shared code) re-checks every SKIP certificate against hashed fact DBs; fail → UNCLEAR. (9) models admitted not trusted: JCG-style idiom probes + dynamic recall (TamiFlex/NodeProf traces ⊆ static graph) + noise gate on held-out probes.
